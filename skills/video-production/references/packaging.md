# Thumbnails and social copy

## Covers

By default, every requested aspect gets a usable cover, even if the request only said “edit this video.” Honor an explicit exception recorded in the brief and manifest. Reuse approved artwork for a revision when it still matches.

Choose a sharp real frame with open eyes and a natural expression. Preserve identity and existing redactions. A short hook should express the actual promise. Favor few words, large type, strong contrast and generous margins.

Use approved covers as style references. Dark teal, white type and yellow accents worked in a recent release; the current brief governs. Use screenshots as evidence, not invented product features. Check readability at phone size and recompose portrait covers instead of clipping landscape art.

Use available image generation/editing tools and the relevant image skill. If that capability is missing, report it and continue independent work; do not silently omit the cover. A selected frame with designed type is appropriate when requested or supported. Save final assets in the production directory.

## Copy

Use the creator's established voice and brand guidance. For a personal walkthrough without other direction, use first person, direct casual language, contractions, and concrete actions and outcomes. No em dashes, corporate enthusiasm, invented metrics or “not X, but Y” framing. Profanity is optional, never forced. Use the LinkedIn writing skill if available; these rules suffice for a portable package.

| Destination | Deliverable |
| --- | --- |
| YouTube | Interesting, searchable title; description with the result, workflow and verified links. |
| YouTube Shorts | Its own title and concise description for the actual vertical edit. |
| Instagram | Editorial title/cover hook and independently pasteable caption. |
| TikTok | Editorial title/cover hook and short conversational caption. |
| LinkedIn | Editorial hook and a first-person post about what the creator did and why it helped. |
| Threads | Editorial hook and conversational short post. |
| Bluesky | Editorial hook and compact standalone post. |
| X | Editorial hook and compact standalone post. |

An editorial hook is not a claim that a platform has a separate title field. Use explicit filenames such as `youtube-title.txt`, `youtube-description.txt`, `instagram-hook.txt`, and `instagram-caption.txt`. Do not prepend a hook that the caption already includes.

Use a few relevant hashtags where useful. Avoid identical paragraphs everywhere. Do not promise replies, giveaways, “link in bio,” or “comment for the link” without an existing path and the user's direction.

When speech promises a workflow download, prepare a shareable artifact and track the missing public URL in setup notes. Keep local paths and placeholders out of paste-ready copy. A local ZIP is ready to share, not a hosted URL. Distinguish demonstrated features from ideas still being explored.

Platform limits, scheduler fields and account connections change. Verify these at publishing time using current official information or connected UI; don't hard-code assumptions from an older session.

Save a combined copy document plus clean per-platform files. The manifest associates each target with a real video, cover, title, description/caption and copy file. Keep asset readiness separate from publication status. Log shipped or scheduled content only after actual confirmation.
